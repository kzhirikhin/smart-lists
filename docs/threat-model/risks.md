## Эксплуатационный backlog

- request_id Vercel/Cloud Run без содержимого и user identifiers.
- CloudTrail data events S3; сначала сверить current state.
- Отдельный restore-путь/IAM-role, рассмотреть SSE-KMS после сверки bucket policy A82.
- Step-up удаления/управления доступом.
- Минимизация свободного AI-текста и groups FastAPI с сохранением нужного контекста/совместимости.
- Durable retry/reconciliation S3 ↔ Attachment для сирот и удаления данных.

Завершённые rollout/старые digest/migration-plan в [архиве](archive-2026-10-14.md), не backlog и не гарантия нынешнего live-состояния.

## Триггеры полного пересмотра

Новая граница/сервис; модель прав/администратор/viewer; hosting/egress; AI provider/model/location/tools; file origin/типы; DB driver/TLS; credentials/IAM/WIF/control plane; scan/VEX/waiver/provenance/SBOM; второй write-участник; число/доверие пользователей; возобновление Anthropic rule; отсутствие успешного scan дольше восьми дней.

Тариф Neon — PITR/branch/network protection. Защита Vercel — основной домен, preview/unique production URL, exceptions/automation bypass A101. Смена структуры/синтаксиса src/CI — границы detector даже при зелёных тестах.

Публичный Docker/desktop/npm/template артефакт — новый license/distribution review. Выводы hosted-состояния о copyleft не переносятся на распространение без проверки формы доставки.

## Перед расширением доступа

Снятие whitelist — отдельное решение владельца. До него проверить tenant/auth/privacy по потоку, rate/structural/storage/file limits для недоверенных пользователей, cost controls, наблюдаемость/response/restore, минимизацию AI и правовое уведомление. Повторно сверить live-привилегии, backup/bucket/network/protection и переоценить риски малого доверенного круга A12.

Это условия будущего решения, не обещание готовности к публичному запуску и не исчерпывающая compliance-проверка.
